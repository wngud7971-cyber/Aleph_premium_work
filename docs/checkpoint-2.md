## 이번에 만든 것

Plan–Do–See 방식으로 계획·운동·하루 회고를 날짜별로 저장하는 Windows 앱을 만들었습니다. 브라우저 없이 로컬에 저장하며, 기본900×880 고정 창에서 날짜 상세와 통계를 열고 마지막 위치·테마·강조색을 기억합니다. 라이트·다크와 강조색 선택, 저장 완료 안내, 미저장 입력 보호를 지원합니다.

운동은 5개 분류의 22개 종목에서 시간·횟수·층수를 직접 입력하고, 체중과 지원 활동 조건을 갖춘 기록에 한해 예상 kcal을 계산합니다. 풋살은 총 참여 시간과 실제 경기 시간을 구분합니다. 주간·월간·요일별 통계에서 계획 완료율, 운동 일수·시간·예상 kcal, 회고 일수를 확인하고 이전 기간과 비교할 수 있습니다.

미완료 계획은 23시에 이월하지만 운동과 회고는 원래 날짜에 유지합니다. 16일 23:59 운동도 16일로 집계하며 지난 날짜에 늦게 기록할 수 있습니다. 선택형 5분 명상 뒤에는 오늘 저장된 미완료 계획을 닫을 수 있는 팝업으로 표시합니다. 트레이 복원과 아이콘 등록 실패 시 작업 표시줄 최소화, 원본을 유지하는 수동 백업과 확인 후 전체 복원도 구현했습니다.

생일·기일·기념일은 한 번 등록하면 매년 표시하고 직접 삭제하기 전까지 남도록 추가했습니다. 양력·음력과 윤달을 구분해 음력 날짜를 해마다 환산하며, 윤달이 없는 해에는 표시하지 않습니다. 원본 규칙과 메모를 저장하고 수정·삭제·백업·복원을 지원합니다. 음력 지원 범위는1900~2050년입니다. 소형 모드와 크기 전환 애니메이션은 제거했으며 최신 글자 크기와 달력 배치는 사용자가 수용했습니다.

## 확인하는 방법 · 3단계 이내

1. 결과물 페이지에서 Windows 2차 시험본 ZIP을 내려받아 전체 압축을 해제하고 START-TEST.cmd를 실행합니다. 시험 기록은 기존 개인 기록과 별도로 저장됩니다.
2. 날짜를 선택해 계획·운동·회고 탭에 입력하고 저장 완료를 확인합니다. 통계에서 해당 날짜를 포함한 기간을 골라 기록 건수·시간·요일 집계를 확인합니다. 운동은 23시 계획 이월과 별개입니다.
3. X로 숨긴 뒤 시험본을 다시 실행해 창을 복원하고, 완전히 종료한 뒤 다시 열어 저장한 기록과 마지막 화면 설정이 유지되는지 확인합니다. 오늘 미완료 계획이 있으면 명상 안내를 닫은 뒤 할 일 팝업도 확인합니다.

## 바뀐 점과 그 이유

처음에는 웹을 생각했지만 사용자가 상시 실행의 CPU·메모리 부담을 우려해 Windows 네이티브 앱을 우선 만들었습니다. 웹은 소개와 디자인 검토용 초안으로 분리했습니다. 디자인 검토를 거쳐 분홍 강조색·영어 월 제목·고운돋움과 소프트 플래너 구성을 적용했고, 밝고 선명한 강조색과 다크 모드에서도 주말 날짜·저장 글자를 읽을 수 있도록 대비를 보완했습니다.

직접 사용 중에는 트레이 아이콘을 찾기 어렵고 모드 전환이 딱딱하다는 피드백이 있었습니다. 시작부터 아이콘을 등록하고 등록 여부를 확인하며, 실패하면 창을 숨기지 않고 작업 표시줄에 남도록 바꿨습니다. 같은 실행 파일을 다시 실행하면 기존 창을 복원합니다. 창 확장 시 화면 밖으로 나가는 상황과 ‘오늘’ 이동 취소 후 표시 월이 바뀌는 상황도 보완했습니다. 이후 사용자가 소형 모드를 없애고 고정 창 하나로 결정해 크기 전환 자체를 제거했습니다.

운동은 늦은 시간에도 할 수 있다는 의견에 따라 23시 이월에서 분리하고 입력 화면에 기록 날짜를 표시했습니다. 통계가 0건으로 보였던 사례는 백업의 운동 날짜가 17일이고 조회 종료일은 16일인 차이를 확인했습니다. 개인 기록의 날짜를 임의 변경하지 않았습니다. 명상은 강제 대기 대신 선택형 타이머로 정했고, 닫거나 완료한 뒤 오늘 남은 일을 알리도록 확장했습니다.

사용자가 명상 숫자의 크기와 위치가 불안정하다고 보고해 타이머의 고정폭 글꼴·고정 배치를 적용했습니다. 현재 고정 창의 라이트·다크에서 전 구간 표시를 자동 검사했으며 최신 디자인은 사용자가 수용했습니다. 주요 변경 전·후와 이유는 plan.md 맨 하단에도 정리했습니다.
