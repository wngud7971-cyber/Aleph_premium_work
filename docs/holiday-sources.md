# 한국 공휴일 자료 · 2026-10-17 확인

앱에 2025~2027년의 날짜·공휴일 명칭이라는 사실 자료를 포함한다. 자동으로 매번 인터넷에 접속하거나 백그라운드에서 갱신하지 않는다. 이후 신규 임시공휴일과 다음 연도는 자료 업데이트가 필요하며 미포함 연도는 달력에 안내한다. 일요일은 기존 요일 색상으로 빨간색을 유지하고, 아래의 지정 공휴일은 요일에 관계없이 빨간색으로 표시한다. 지역 공휴일·회사 휴무·모든 기념일을 국가 공휴일로 취급하지 않는다.

## 자료와 후속 변경

- [KASI 2025 달력자료](https://astro.kasi.re.kr/kor/life/post/calendarData?search_year=2025): 정기 공휴일·음력 연휴·대체공휴일의 월일을 대조했다. 해당 표는 초기 생성 이후의 임시공휴일·선거일을 모두 반영한 자료가 아니므로 아래 정부 발표를 추가한다. 2025년 제헌절은 국경일이지만 공휴일로 넣지 않고 노동절도 국가 공휴일로 넣지 않는다.
- [KASI 2026 달력자료](https://astro.kasi.re.kr/kor/life/post/calendarData?year=2026): 설날·부처님오신날·추석·지방선거와 대체공휴일을 대조했다. 초기 자료에 누락된 노동절은 후속 인사혁신처 발표로 보완했다.
- [KASI 2027 달력자료](https://astro.kasi.re.kr/kor/life/post/calendarData?year=2027): 설날과2월9일 대체, 노동절과5월3일 대체, 제헌절과7월19일 대체 등 명시된 날짜를 대조했다.
- [우주항공청 2027년 월력요항 공고](https://www.kasa.go.kr/bbs/BBSMSTR_000000000018/view.do?nttId=B000000003234Li6nD2): 2026.06.29 발표 공고 존재를 확인했다. 본 구현의 표 대조는 위 KASI 웹 자료를 사용했으며 PDF 첨부 전체를 별도로 판독한 것으로 주장하지 않는다.
- [인사혁신처: 올해부터 노동절·제헌절 공휴일](https://www.mpm.go.kr/mpm/comm/newsPress/newsPressRelease/?boardId=bbs_0000000000000029&category=&cntId=4250&mode=view&pageIdx=1): 2026년부터 노동절5월1일·제헌절7월17일이 공휴일이며 대체공휴일도 적용됨을 확인했다. 이 변경을2025년으로 소급 적용하지 않는다.
- [인사혁신처 2025년1월 소식지](https://www.mpm.go.kr/mpm/comm/newsLetter/?boardId=bbs_0000000000000033&category=&cntId=222&mode=view&pageIdx=): 2025.01.27 임시공휴일 지정을 추가했다.
- [중앙선거관리위원회 선거 안내](https://www.nec.go.kr/portal/contents.do?menuNo=2000010): 2025.06.03 제21대 대통령선거 날짜를 확인해 추가했다. 2026.06.03 전국동시지방선거는 해당 연도 KASI 자료와도 대조했다.

KASI 달력자료 페이지는 공식 발표 전 자료라는 주의 문구가 있으므로, 모든 연도의 공휴일을 영구 확정하거나 변경 가능성이 없다고 표현하지 않는다. 본 앱은2026.10.17에 확인한 해당 기간의 자료를 제공한다. 저작물의 PDF·문장·이미지를 재배포하지 않고 달력 사실의 월일·명칭만 코드로 제공하며 출처를 함께 보관한다.

## 집계와 경계

일요일을 별도로 세지 않은 지정 공휴일의 서로 다른 날짜는2025년19일·2026년22일·2027년24일이다. 2025.05.05의 어린이날·부처님오신날은 같은 날짜 아래 두 이름을 보존한다. 토요일과 겹친 현충일이나2026년 추석 때문에 임의의 월요일 대체공휴일을 만들지 않는다. 공휴일은 앱 기본 자료이며 개인 계획·기념일·통계·23시 이월·수동 백업에 새로운 기록으로 저장하지 않는다.
