## 재검사에서 수정한 검사 조건

첫 애니메이션 프레임이 아직 닫힌 상태일 때 들어온 닫기 요청은 정상 즉시 완료가 가능합니다. 이전 검사가 모든 중간 요청의 취소만 기대해 실패하는 것을 확인했습니다. 실제 도착 상태에서만 정상 완료를 허용하고, 마지막 요청이 최종 너비·표시 상태를 결정하며 남은 클록을 정리하는 검증은 유지합니다. 실제 앱의 이동·저장 정책을 바꾸지 않았습니다.

## 자동 검사와 사용자의 판단

작성자가 직접 계획·운동·회고 입력, 타이머·트레이 복원·운동 통계·재실행, 창 크기·글꼴·배치·전환을 확인하고 피드백을 제공했습니다. 이를 다수 사용자나 모든 기능의 실제 조작 검증으로 확대하지 않습니다. 자동 버튼 이벤트와 모의 배율도 실제 포인터·OS 배율 변경과 구분합니다.

## 남은 확인
