일상의 기록을 한곳에서

계획과 하루 회고

날짜별 계획·시간·메모·완료 상태와 하루 회고를 저장합니다. 미완료 계획만 23시에 다음 날로 이월합니다.

운동과 예상 kcal

5개 분류·22개 종목의 시간·횟수·층수를 기록합니다. 유효한 체중·시간·지원 활동 조건을 갖춘 기록만 예상 kcal을 계산합니다.

학습과 첨부 자료

제목·내용·직접 요약·소요 시간을 기록하고 모아봅니다. 첨부는 사본으로 보관하므로 원본을 지워도 보관한 자료를 열 수 있습니다.

가계부와 월 정기 내역

수입·지출, 주간·월간 누적과 소비 유형을 확인합니다. 정기 내역은 지정일에 자동 반영하고 적금·저축은 소비와 구분합니다.

통계와 기록 관리

주간·월간·요일별 통계, 12개월 선 그래프, 통합 검색·휴지통·월간 결산과 예산을 같은 앱 안에서 확인합니다.

기념일과 보관

양력·음력 기념일, 한국 공휴일, 명상과 오늘 할 일 안내를 제공합니다. 트레이로 숨겨 두고 수동 백업·복원으로 기록을 보관합니다.

운동은 늦게 입력해도 선택한 날짜의 기록입니다.
16일 23:59에 16일 운동을 저장하면 16일로 집계합니다. 자정 이후에도 수행한 날짜를 선택해 입력할 수 있습니다. 운동·학습·금전은 계획의 23시 이월 대상이 아닙니다.

세 단계로 확인하세요

  1. 실행 ZIP 전체를 풀고 START-TEST.cmd를 실행합니다.같은 위치의 PDS 폴더를 함께 유지하세요. 별도 SDK 설치 없이 실행할 수 있습니다.
  2. 날짜를 선택해 계획·운동·학습·가계부를 저장합니다.저장 완료를 확인하고, 완전히 종료했다가 다시 열어 기록이 유지되는지 확인하세요.
  3. 통계와 기록 관리에서 결과를 돌아봅니다.기간별 통계·검색·휴지통·월간 결산·연간 그래프를 확인합니다. 백업·복원은 별도의 시험 기록으로 점검하세요.

START-TEST.cmd는 %LOCALAPPDATA%/PdsFunctionalPreview에 저장합니다. 이전 시험 기록이 있으면 이어서 사용하며, 개인 기본 저장소와는 분리됩니다. X는 트레이 숨김이고 ‘완전히 종료’는 실제 종료입니다.

백업·복원과 첨부 파일은 어떻게 보관하나요?

백업 내보내기는 원본 기록을 삭제하지 않습니다. 학습 첨부를 포함하는 ZIP 백업을 지원하며, 복원은 확인 후 현재 기록·설정을 교체합니다. 실제 개인 기록을 복원하기 전에는 현재 기록을 먼저 내보내 보관하세요.

인터넷이나 회원가입이 필요한가요?

Windows 앱의 기록은 SQLite DB와 앱이 관리하는 첨부 폴더에 로컬 저장합니다. 회원가입과 자동 클라우드 동기화는 제공하지 않습니다. 이 소개 사이트는 앱의 개인 기록을 읽거나 저장하지 않습니다.

확인한 범위도 함께 공개합니다

기록 저장·통계·날짜 경계·첨부 보관·백업·복원과 화면 흐름을 별도 시험 데이터로 검사했습니다. 자동 검사와 실제 사용자 평가를 구분합니다. 모든 PC나 장기간의 성능을 보장한 것으로 확대하지 않습니다.
