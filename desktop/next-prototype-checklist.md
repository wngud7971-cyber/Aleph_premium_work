# PDS · Windows 최종 공개본

현재 기능·실행 ZIP·검증 범위는 [루트 README](../README.md)를 따릅니다. `desktop/artifacts`와 `.tools`는 공개 소스에 포함하지 않습니다.

## 실행과 빌드

- 일반 사용: 릴리스의 실행 ZIP 전체 압축 해제 후 START-TEST.cmd. 런타임 포함.
- 소스: Windows x64와 .NET10 SDK가 필요합니다. `global.json`은10.0.402 기능 대역을 사용합니다.
- `./build.ps1`: Release 빌드와 코어390개 검사.
- `./run.ps1`: 소스에서 빌드한 앱을 별도 시험 저장소로 실행.
- `./prepare-candidate.ps1 -BundleName PDS-Windows-x64-local-test`: 새 자체 포함 실행 폴더 생성.
- `./verify-candidate.ps1 -BundleName PDS-Windows-x64-local-test`: 해당 실행 파일의 화면·재실행·트레이 확인.

검사는 개인 기본 저장소와 분리한 합성 기록으로 실행합니다. 자동 검사와 실제 사용자·환경 확인을 구분합니다. Windows 로그인 자동 실행 설정은 시험 실행으로 변경하지 않습니다.

계획·운동·회고·가계부·학습은 날짜별로 저장합니다. 계획만23시 이월하고 다른 기록은 선택 날짜를 유지합니다. 데이터 형식12·백업v8이며 첨부 사본과 ZIP 백업을 지원합니다. 학습 파일 분석·자동 요약·클라우드 동기화는 제공하지 않습니다.

앱과 검사 코드에는 임시 합성 기록과 검증 모드가 포함됩니다. 실제 사용자를 위한 예시 기록을 자동 생성하지 않습니다. 공휴일2025~2027년·음력1900~2050년 범위와 나머지 제한은 검증 문서를 참고하세요.
