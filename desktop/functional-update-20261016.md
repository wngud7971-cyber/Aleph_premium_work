## 검증 결과

- `build.ps1`: Release 빌드 성공, 경고·오류 0개. 코어·통신·대비 검사 **42개 통과**.
- SQLite: 저장·재열기, 수정 시 ID 유지, 날짜 구분, 삭제, 잘못된 입력, 이전 수정본의 덮어쓰기 방지, 다른 날 ID 충돌 시 계획·운동·수정 번호 전체 롤백을 검사했다.
- 업그레이드: 이전 형식 1의 계획·시간·메모·완료·수정 번호를 보존하면서 형식 2로 변경했다. 개인 DB가 아닌 검증용 이전 형식 DB를 사용했다. 새 형식 DB는 이전 앱이 열지 않으므로 배포 시 버전 전환 안내가 필요하다.
- 명상: 제어 가능한 시계로 시작 전, 65초 경과, 중도 닫기, 화면 갱신 없이 5분 초과 후 완료를 검사했다. 실제로 5분 대기하는 수동 명상 검사는 이번 범위에 포함하지 않는다.
- 복원 통신: 요청·응답, 반복 요청, 서버 부재 시 제한 시간, 데이터 폴더 격리를 검사했다.
- 대비: 125개 강조색에서 선택 주말 날짜와 저장 글자의 대비를 확인했다. 다크 모드의 운동 입력·선택 화면 PNG를 확인했다.
- `verify-features.ps1`: WPF 흐름 **29개 통과**. 실제 XAML과 저장 이벤트를 통해 계획·운동 동시 저장, 입력 오류 보존, 탭/테마 변경, 숨김/복원, 명상 시작/닫기, 운동 수정·삭제·날짜 이동을 검사했다. 29개 중 한 항목에는 일반/소형 각 3크기×4·5·6주 달력의 **18개 배치 조합**이 포함된다. 검사 횟수를 사용자 수나 사용 기간으로 환산하지 않는다.
