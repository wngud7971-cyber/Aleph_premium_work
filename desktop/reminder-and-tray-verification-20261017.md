# 운동 날짜·오늘의 할 일·트레이 보완 · 2026-10-17

## 적용 내용

- 운동은 자정 기준의 달력 날짜에 기록한다. 16일 23:59 운동은 16일이며 23시 계획 이월을 적용하지 않는다. 자정 이후의 뒤늦은 기록도 지난 날짜를 선택하면 그 날짜로 저장·집계한다. 수행 날짜를 입력 화면과 저장 안내에 표시한다.
- 운동만 있는 날짜의 건수는 `운동: 3건`으로 표시한다. 작은 칸에서는 말줄임과 도움말을 제공한다.
- 앱의 하루 첫 명상을 닫거나 건너뛰거나 5분을 마치면 오늘의 저장된 미완료 계획을 알린다. 같은 날 앱을 다시 실행하거나 트레이에서 복원해도 남은 계획을 다시 알린다. 단순 창 활성화마다 반복하지 않는다.
- 명상을 끄면 바로 할 일을 알리고, 남은 계획이 없으면 팝업을 생략한다. 팝업의 X·닫기·Esc는 기록을 수정하지 않는다. `오늘의 계획 열기`는 미저장 세 탭 입력을 보호한다.
- 트레이 아이콘을 앱 시작부터 네이티브 셸 API로 등록하고 실제 아이콘 영역 조회로 등록 여부를 확인한다. 최초 실패는 세 번까지 재시도한다. X에서 등록을 확인하지 못하면 작업 표시줄에 최소화한다. 셸 재시작 메시지의 재등록도 구현했다.

## 날짜 누락 조사

사용자가 제공한 `pds-check.json`은 읽기 전용으로 확인했다. 운동 3건·75분은 17일에 저장되어 있었고, 제공된 화면의 통계 범위는 16일까지였다. 조사 중 개인 기록의 날짜·내용을 수정하지 않았다. 제목·메모·체중 등은 진단 출력이나 이 보고서에 포함하지 않았다. 백업 원문은 실행 묶음에 포함하지 않는다.

직접 DB 경로는 Codex 앱 격리 때문에 오래된 별도 캐시로 연결되어 실제 원본 확인 근거로 쓰지 않았다. 사용자가 만든 내보내기 파일의 날짜별 집계만 원인 판단에 사용했다. 23시 이후 운동을 제외하는 필터가 원인이라고 단정하지 않는다.

## 실행 묶음과 남은 확인

최신 시험 묶음 이름은 `PDS-Windows-x64-reminder-20261017`이다. 개인 앱과 이전 Oct16 묶음을 덮어쓰지 않는다. ZIP 전체를 해제한 뒤 `START-TEST.cmd`로 실행하면 별도 `PdsFunctionalPreview` 저장소를 사용한다. 이 안내는 exe를 직접 실행하는 경우와 구분한다. exe 직접 실행은 기존 개인 저장소를 사용한다.

현재 실행 중인 개인 앱·개인 DB·시작 프로그램 등록·마우스·공개 GitHub/Vercel은 변경하지 않았다. 실제 사용자 아이콘 클릭과 우클릭 메뉴, Windows 셸 재시작, 로그인, 절전·복귀, 장기 사용과 전환의 체감은 별도 확인이 필요하다. 아이콘 등록 성공은 시계 옆에 항상 노출된다는 뜻이 아니며 Windows 숨긴 아이콘 영역에 배치될 수 있다.

이번 변경으로 자원 사용 목표 달성을 새로 주장하지 않는다. 10월 16일 측정값과 제한은 `statistics-rollover-backup-verification-20261016.md`에 남긴다. 데이터 형식 5와 수동 백업 형식 v1은 유지한다.
