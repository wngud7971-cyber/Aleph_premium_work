# PDS · 첫 Windows 시제품

브라우저 없이 실행되는 Windows 캘린더와 계획 기록 앱입니다. 현재는 기본 창·실제 저장·대기 자원 사용량을 확인하는 첫 시제품이며 중간 점검 1차의 전체 기능을 완료한 버전은 아닙니다.

## 실행

`PDS-실행.cmd`를 더블 클릭합니다. 또는 `artifacts/PDS-preview/Pds.Desktop.exe`를 실행합니다.

실행 폴더의 다른 파일도 함께 필요합니다. exe 하나만 다른 곳으로 옮기면 실행되지 않을 수 있으므로 `PDS-preview` 폴더 전체를 보관하세요. 실행 묶음에는 필요한 .NET 런타임이 들어 있어 별도의 SDK 설치 없이 실행할 수 있습니다.

## 지금 사용할 수 있는 기능

- 월요일부터 시작하는 월간 캘린더, 실제 4·5·6주 표시, 오늘 이동과 날짜 선택.
- 정사각형 날짜 칸, 토요일 파란색·일요일 빨간색.
- 날짜 선택 시 오른쪽 상세 열기, 계획 제목·선택 메모·선택 시간 입력.
- 계획 추가·수정·삭제·완료 체크. **저장 버튼을 눌러야 기록에 반영**되며 성공하면 `저장 완료`가 표시됩니다. `Ctrl+S`도 지원합니다.
- 날짜 변경·상세 닫기·모드 전환·완전 종료 시 미저장 내용 확인. 실패하면 입력을 유지합니다.
- SQLite 로컬 저장과 앱 재실행 후 복구. 예시 기록은 개인 DB에 자동 생성하지 않습니다.
- 일반 창·소형 모드, 마우스 크기 조절, 마지막 크기·모드·위치 기억. 작은 창에서는 달력을 스크롤합니다.
- 라이트·다크, 강조색 선택과 기본 파스텔 노랑 복귀.
- 하루 첫 사용 시 닫을 수 있는 5분 명상 안내. 실제 수행 기록이나 타이머는 없습니다.
- `X`는 트레이로 숨김. 트레이에서 다시 열거나 `완전히 종료`로 종료할 수 있습니다. 소형 모드의 항상 위는 기본 꺼짐입니다.

## 아직 구현하지 않은 기능

운동·kcal 계산·체중 확인, 하루 회고, 주간·월간·요일별 통계, 23시 자동 이월, 파일 내보내기·복원, Windows 로그인 자동 실행, 태블릿 지원은 다음 작업입니다. **이 시제품에서는 23시가 되어도 계획이 이동하지 않습니다.** 현재 PC의 자동 실행 설정을 등록하지 않습니다.

장시간 실행, 절전·다중 모니터·Windows 셸 재시작·세션 종료 등의 경계 조건은 추가 검증이 필요합니다. 본 제품의 최종 최소 창 크기를 확정한 것은 아닙니다.

## 기록 위치

기본 개인 기록은 `%LOCALAPPDATA%/PdsPrototype/records.db`, 설정은 같은 폴더의 `settings.json`에 저장합니다. 앱을 닫거나 프로그램 폴더를 옮겨도 이 기록을 지우지 않습니다. DB 서버·계정·인터넷 연결이 필요하지 않습니다.

검증에는 개인 기록과 분리된 별도 폴더를 사용했습니다. 검증 실행이 일반 개인 기록 폴더를 사용하지 않도록 분리합니다.

## 개발

- Windows 11 x64 / C# / WPF / .NET 10.
- SDK는 `global.json`의 `10.0.402`로 고정합니다. 개발에는 .NET 10 SDK가 필요하며 실행 묶음에는 런타임이 포함되어 있습니다.
- SQLite 패키지는 `Microsoft.Data.Sqlite 10.0.13`입니다. 패키지와 SDK는 배포 파일에 포함하지 않으며 런타임만 실행 묶음에 포함합니다.
- `Pds.Core`: 기록 모델·검증·원자적 DB 저장·동시 수정 충돌 감지.
- `Pds.Desktop`: WPF 창·입력·화면 상태·설정·트레이.
- `Pds.Checks`: 개인 데이터와 분리된 임시 DB로 저장·검증·실패 시 보존을 확인하는 15개 검사.

`build.ps1`은 Release 빌드와 저장 검사를 실행합니다. `build.ps1 -Package`는 실행 묶음도 만듭니다. 처음 복원·패키징할 때는 Microsoft NuGet에 연결할 수 있어야 합니다.

이 첫 시제품의 화면 이벤트는 작은 코드 비하인드로 연결했습니다. 기록 검증과 저장은 별도 코어에 있으며, 운동·회고·통계를 추가할 때 화면 상태를 ViewModel로 분리할 예정입니다. 전체 MVVM 전환을 완료했다고 표시하지 않습니다.

공식 개발 도구 출처: [Microsoft .NET 다운로드](https://dotnet.microsoft.com/en-us/download/dotnet/10.0), [Microsoft.Data.Sqlite](https://learn.microsoft.com/en-us/dotnet/standard/data/sqlite/).

성능 측정 조건과 결과는 [검증 문서](../docs/verification.md)에 정리했습니다.
