# PDS · Windows 중간 점검 2차

날짜별 계획·운동·회고를 PC에 저장하고 주간·월간·요일별 통계를 확인하는 Windows 앱입니다. 기본 분홍 #E3BACA와 라이트·다크·색상 선택을 지원합니다. 기본900×880의 고정 창 하나를 사용하며 소형 모드를 제거했습니다. 날짜 상세와 통계는 같은 창에서 열고 위치·테마·강조색을 기억합니다. 작업 영역이 더 작은 화면에서만 고정 크기를 보정합니다.

## 시험본 실행

PDS-Windows-x64-stage2-legible-20261017.zip 전체를 풀고 **START-TEST.cmd**를 실행하세요. 런타임이 포함되어 별도 SDK 없이 실행합니다. exe 하나만 옮기지 말고 폴더 전체를 유지하세요.

시험 기록은 %LOCALAPPDATA%/PdsFunctionalPreview에 저장합니다. 기존 개인 기록과 별도이며 예시 기록을 자동 생성하지 않습니다. exe 직접 실행은 기존 개인 저장소를 사용하므로 이번 점검은 START-TEST.cmd로 진행하세요. 소스의 PDS-실행.cmd와 run.ps1도 시험 저장소를 기본으로 사용합니다. 사용 중인 앱·개인 기록·시작 프로그램은 시험 실행으로 변경하지 않습니다.

## 주요 동작

- 날짜를 누르면 오른쪽 상세 영역이 열립니다. 계획·운동·회고 탭의 변경은 저장 버튼 또는 Ctrl+S로 함께 저장하며 성공 후 저장 완료와 날짜를 표시합니다.
- 계획 제목·시간·메모·완료를 수정하거나 삭제할 수 있습니다. 미저장 입력을 보호하며 오늘 이동을 취소하면 날짜·표시 월도 유지합니다.
- 5개 분류22개 운동의 시간·횟수·층수를 직접 입력합니다. 시간 없는 기록에 임의의 시간·kcal을 만들지 않고 풋살의 총 참여·실제 경기 시간을 구분합니다.
- 기본 체중은14일마다 갱신합니다. 지원 활동·수행 시간·유효 체중이 갖춰진 기록만 예상 kcal을 계산하며 새 체중으로 과거 계산을 바꾸지 않습니다.
- 회고 세 칸은 모두 선택 입력입니다. 주간·월간·요일별 통계와 이전 기간 비교, 운동 분류·종목 필터를 제공합니다.
- 미완료 계획만23시에 이월합니다. **16일23:59 운동은16일**이며 자정 후에도 수행한 날짜를 선택하면 그 날짜로 집계합니다. 운동과 회고는 이월하지 않습니다.
- 선택형5분 명상 뒤 오늘의 저장된 미완료를 알립니다. 명상은 언제든 닫고 팝업은 X·닫기·Esc로 닫습니다. 닫기는 완료·삭제·자동 저장을 뜻하지 않습니다. 같은 날 다시 열거나 트레이에서 복원하면 남은 일을 다시 알립니다.
- X는 트레이 숨김입니다. 시계 옆 분홍 P(숨긴 아이콘 포함)를 누르거나 시험본을 다시 실행하면 같은 창을 복원합니다. 아이콘 등록이 확인되지 않으면 작업 표시줄에 최소화합니다. 하단의 완전히 종료는 실제 종료입니다.
- 수동 백업 내보내기는 원본을 유지합니다. 복원은 확인 후 현재 기록과 설정 전체를 교체하며 취소·오류는 원본을 유지합니다.

## 검증과 제한

코어205개·WPF204개와 새 프로세스의 회고·계획·운동 복구를 통과했습니다. 런타임 포함 파일 자체의 검사와 많은 기록·상주 측정은 [2차 검증 보고서](stage2-verification-20261017.md)를 따릅니다.

본인1명의15개 점검은12개 기본 동작 확인·3개 미확인/설명 필요로 기록합니다. 새 버전의 사용자 재확인·추가 참여자·7일 실사용을 임의로 만들지 않습니다. 실제 트레이 클릭·로그인·절전·다중 모니터·다양한 배율의 사용자 환경 검사는 남아 있습니다.

## 소스 빌드

Windows x64와 .NET10 SDK가 필요하며 개발 스크립트는 PowerShell7.6.5에서 확인했습니다. global.json은10.0.402와 같은 기능 대역의 최신 패치를 선택합니다. 전용 .tools/dotnet이 없으면 설치된 dotnet을 사용합니다.

1. desktop에서 ./build.ps1: Release 빌드와 코어 검사.
2. ./verify-features.ps1: 별도 데이터·비활성 화면 밖의 WPF 흐름과 재실행 검사.
3. ./verify-tray.ps1: 자체 임시 아이콘의 실제 등록·최소화·초안 복원. 개인 앱·마우스를 조작하지 않습니다.
4. ./verify-endurance.ps1: 가상500일 데이터·30분 상주와 반복 전환 검사. 시작 프로그램은 변경하지 않습니다.
5. ./prepare-candidate.ps1 후 ./verify-candidate.ps1: 새 런타임 포함 묶음 생성과 해당 파일 자체 검사. 같은 이름은 덮어쓰지 않습니다.

검사 결과는 artifacts에 저장하며 소스·배포에서 제외합니다. SQLite 형식7과 수동 JSON v3를 사용하며 기존 v1/v2 백업도 읽습니다. 형식7 DB를 이전 앱에서 다시 여는 것은 지원하지 않습니다. run.ps1의 UsePersonalRecords 옵션은 개인 저장소를 선택하므로 별도 시험에는 사용하지 않습니다.

## 2026-10-17 기념일 추가 시험

상단 기념일에서 생일·기일·기념일을 양력/음력으로 등록하면 매년 표시합니다. 윤달 없는 해는 기본 생략이며 원본 규칙은 유지합니다. 음력1900~2050년, 월일 부재 시 마지막 날/해당 해 생략을 선택합니다. 현재는 형식7·백업v3이며 기존v1/v2백업을 읽습니다. 기존 시험 앱을 완전히 종료한 후 새 실행 안내 파일을 사용하세요. 소형·크기 전환·항상 위 기능은 제거했습니다. 최신 디자인을 사용자가 수용해 최종 Git 업로드 묶음을 정리했습니다.

## 원본 생년월일 추가 시험

연도·월일과 원본 달력을 입력하고 매년 반복 기준을 고르면 자동 환산합니다. 양력 날짜에서 음력 윤달 여부를 자동 판별하고 음력의 평달/윤달이 모두 가능한 원본에만 한 번 선택을 요구합니다. 연도 미상인 기존 기록은 유지합니다. 형식7·백업v3이며 v1/v2백업도 읽습니다. 현재 기능·검사 근거는 검증 보고서의 생년월일 절을 따릅니다.

## 생일 표기와 한국 공휴일

기념일은 구분: 이름으로 표시하고 좁은 칸에서 두 줄을 사용합니다. 한국2025~2027년 공휴일은 날짜 숫자와 이름을 빨간색으로 표시합니다. 자료 확인일은2026.10.17이며 미포함 연도는 화면에 안내합니다. 출처와 후속 변경은 korean-holiday-sources-20261017.md를 따릅니다. 형식7·백업v3를 유지하고 개인 기록·통계에 공휴일을 추가 저장하지 않습니다.

공휴일 이름은 날짜 오른쪽, 생일·건수는 그 아래에 배치합니다. 요일 줄은 고정하고4/5/6주 전체가 세로 스크롤 없이 보입니다. 상세를 열어 가로 폭이 부족하면 가로 스크롤로 확인합니다. 배치·크기·기준선 변경 이유는 plan.md v1.62의16.5~16.8절에 기록했습니다. 모든 날짜 칸과 배경은 공통 크기를 사용하며 공휴일 첫 줄과 날짜는 같은 글꼴의 실제 보이는 높이를 맞춥니다. 앱이 그리는 글씨는1pt씩 확대했고 공휴일은 보이는 높이 보정을 우선합니다.
