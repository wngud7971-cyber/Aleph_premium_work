# PDS · 중간 점검 2차

날짜별 계획·운동·회고와 주간·월간·요일별 통계를 제공하는 Windows 앱입니다. 기본900×880 고정 창, 세로 스크롤 없는 월간 달력, 오른쪽 상세, 라이트·다크·강조색 선택을 제공합니다. 작성자가 최신 글자 크기와 달력 배치를 수용한 버전의 소스·소개 사이트·제출 자료입니다.

## 무엇을 올리나요?

이 폴더의 **내용**을 기존Aleph_premium_work 저장소 루트에 반영합니다. 소스 ZIP 자체만 올리는 것이 아닙니다. 순서는 [UPLOAD.md](UPLOAD.md)에 있습니다. 공개 GitHub/Vercel은 이 묶음 준비만으로 변경되지 않습니다.

## Windows 실행

별도의 **PDS-Windows-x64-stage2-legible-20261017.zip**을 모두 풀고 START-TEST.cmd를 실행합니다. 이 소스 ZIP에는 실행 파일이 없습니다. 검증한 실행 ZIP은 그대로 유지했으며 안의plan.md v1.62는 당시 문서입니다. 최신 제출용 계획서는 이 소스의docs/plan.md v1.63입니다.

시험 데이터는 %LOCALAPPDATA%/PdsFunctionalPreview입니다. 기존 시험 기록을 유지하며 예시를 자동 생성하지 않습니다. X는 트레이 숨김, 같은 실행 안내 파일을 다시 실행하면 기존 창 복원, 완전히 종료는 종료입니다. exe 직접 실행은 기존 개인 저장소를 사용하므로 시험에는 START-TEST.cmd를 사용합니다.

## 구현 범위

- 계획 추가·수정·삭제·완료·선택 시간·메모와 선택형3칸 회고.
- 5개 분류22개 운동의 시간·횟수·층수 직접 입력,14일 체중 갱신, 조건이 맞는 활동의 예상 kcal.
- 주간·월간·요일별 통계와 운동 필터·이전 기간 비교. 운동은23:59에도 선택한 수행 날짜로 저장.
- 미완료 계획만23시 이월. 운동·회고·기념일은 이월하지 않음.
- 양력·음력 생일/기일/기념일의 매년 표시, 원본 생년월일 자동 환산·윤달 없는 해 생략. 음력 지원1900~2050년.
- 한국2025~2027년 확인한 공휴일과 자료 미포함 연도 안내.
- 선택형5분 명상과 이후 오늘의 미완료 팝업. 언제든 닫기와 미저장 보호.
- 트레이·재실행 복원, 원본을 유지하는 백업 내보내기와 확인 후 전체 복원. 형식7·백업v3, 기존v1/v2읽기.

소형 모드·항상 위·크기 전환은 제거했습니다. 초기웹초안에 남은 이전 설계는 현재 Windows 기능으로 해석하지 않습니다.

## 검증과 남은 확인

코어205개·최종 WPF204개·트레이7개·별도 프로세스 기록 복구를 통과했습니다. 두 테마·상세 유무·4/5/6주12조합의 전체 행 표시, 글자 확대·윤곽 높이·명상301값도 확인했습니다. 작성자의 최신 디자인 수용과 자동 검사를 구분합니다.

이전30분/500일 가상 데이터 측정은 기념일·고정 창·글씨 확대 추가 전 결과입니다. 현재 성능을 다시 측정한 것으로 제시하지 않습니다. 실제7일 사용·추가 사용자·로그인·절전/복귀·여러 모니터/배율·셸 재시작은 별도입니다. 태블릿·동기화·바탕화면 위젯은 후속 범위입니다.

## 소스 빌드

Windows x64와 .NET10 SDK가 필요합니다. desktop/global.json의 SDK기능 대역, 프로젝트의 패키지 버전을 사용합니다. desktop에서 build.ps1로 빌드/코어 검사를 실행하고 verify-features.ps1로 별도 데이터의 화면/복구 검사를 수행합니다. 상세 안내는 [desktop/README.md](desktop/README.md)에 있습니다.

SDK·패키지 캐시·bin/obj·개인 DB/백업/설정·인증·실행 파일은 이 소스에 포함하지 않았습니다. 공개 배포 후 다운로드와 페이지를 확인한 다음 제출 URL을 사용하세요.
