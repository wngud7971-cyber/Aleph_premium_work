# PDS · 하루를 가볍게

계획·실행·회고와 운동 기록을 함께 관리하기 위해 개발 중인 Windows 캘린더 앱입니다. 현재 첫 시제품은 **계획 기록과 실제 로컬 저장**을 중심으로 구현했습니다.

## Windows 시제품 다운로드

[Windows x64 실행 파일 묶음 받기](https://github.com/wngud7971-cyber/Aleph_premium_work/releases/download/v0.1.0-preview/PDS-Windows-x64-v0.1.0-preview.zip)

1. ZIP 전체를 압축 해제한 뒤 `Pds.Desktop.exe`를 실행합니다.
2. 날짜를 선택해 계획을 입력하고 저장합니다. 수정·삭제·완료 체크도 저장 버튼을 눌러 반영합니다.
3. 하단의 `완전히 종료`를 누르고 다시 실행해 기록이 남는지 확인합니다.

필요한 런타임이 포함되어 있어 별도 .NET SDK 설치 없이 실행할 수 있습니다. 실행 파일을 다른 곳으로 옮길 때는 폴더 전체를 함께 보관하세요. Windows 11 x64에서 확인했습니다.

## 실제 앱과 웹 화면 초안

- **Windows 앱:** 실제 계획 저장·수정·삭제·완료 체크와 재실행 복구를 지원합니다. 첫 시제품의 외형은 기능 검증을 위해 단순화했습니다.
- **웹 화면 초안:** `site/preview.html`은 확정 디자인과 입력 흐름을 검토하는 예시 화면입니다. 운동·회고·통계 화면의 예시는 Windows 앱 구현 완료를 뜻하지 않습니다. Windows 기록과 연동되지 않습니다.

앱의 일반·소형 모드, 창 크기 조절·기억, 라이트·다크와 강조색 선택, 명상 안내, 트레이 숨김·복원·완전 종료를 구현했습니다.

운동·kcal·체중 확인·회고·통계·23시 이월·수동 백업/복원·Windows 자동 실행은 다음 개발 범위입니다. 현재 앱에서는 23시에 계획이 이동하지 않습니다.

## 검증

독립된 임시 DB 검사 15개와 실제 WPF 앱의 저장·재실행 복구 검사를 통과했습니다. [검증 범위와 성능 표본](docs/verification.md)을 확인하세요. 짧은 표본이며 최종 성능 보장이나 장시간 안정성 검증은 아닙니다.

## 소스와 배포

- `desktop/`: WPF 앱·저장 코어·검사 코드. [개발 안내](desktop/README.md).
- `site/`: 소개·실행 안내와 별도로 표시한 웹 화면 초안.
- Windows 실행 파일은 GitHub Releases, 소개·미리보기는 Vercel 정적 사이트로 배포합니다.
- 개인 DB·개인 설정·인증 파일·개발 SDK·패키지 캐시는 이 저장소와 다운로드 파일에 포함하지 않습니다.

기본 개인 기록은 `%LOCALAPPDATA%/PdsPrototype`에 저장됩니다. 웹 사이트로 개인 기록을 전송하지 않습니다.
